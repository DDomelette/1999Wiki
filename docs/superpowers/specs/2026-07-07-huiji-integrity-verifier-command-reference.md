# Huiji res1999 Integrity Verifier Command Reference

Date: 2026-07-07
Project: `1999Search`
Scope: local-only verification for `data\huiji\res1999`.

This verifier does not access HuijiWiki, Cloudflare, or any remote CDN. It only reads local files generated by the crawler and downloader.

## Command

Run from the project root:

```powershell
cd D:\PycharmProjects\nlp\LangChain\1999Search
conda activate 1999wiki
.\verify_huiji_res1999.bat
```

Lower-level entry points:

```powershell
.\verify_huiji_res1999.ps1
python scripts\verify_huiji_res1999.py
```

## What It Checks

- A completed Full crawl run exists in `crawl_state.sqlite`.
- Each namespace scan recorded by the latest Full run is completed.
- Every active page in SQLite has `last_fetched_revid == lastrevid`.
- Every active page has a matching latest revision in `wikitext.jsonl`.
- Every Data page has a matching latest revision in `data_pages.jsonl`.
- `pages.jsonl`, `wikitext.jsonl`, `data_pages.jsonl`, and `resources_manifest.jsonl` are valid JSONL.
- Every resource in SQLite exists in `resources_manifest.jsonl`.
- Every resource has a safe local path under `data\huiji\res1999`.
- Every resource has `download_status = downloaded`.
- Every downloaded resource file exists locally.
- File size matches the manifest size when a size is available.
- File sha1 matches the manifest sha1 when a sha1 is available.

## Useful Options

Skip sha1 hashing for a faster structural check:

```powershell
.\verify_huiji_res1999.bat -SkipResourceHash
```

Limit the number of printed issue samples:

```powershell
.\verify_huiji_res1999.bat -IssueLimit 50
```

Use a custom output root:

```powershell
.\verify_huiji_res1999.bat -Out D:\somewhere\res1999
```

Emit JSON only:

```powershell
.\verify_huiji_res1999.bat -Json
```

## Expected Workflow

```powershell
.\crawl_huiji_res1999.bat -Mode DryRun -Transport Edge -EdgePort 9333
.\crawl_huiji_res1999.bat -Mode Full -Transport Edge -EdgePort 9333
.\download_huiji_resources.bat -Workers 2
.\download_huiji_resources.bat -Workers 1 -IncludeFailed
.\verify_huiji_res1999.bat
```

`.\verify_huiji_res1999.bat` returns exit code `0` only when no integrity errors are found.
